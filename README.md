# 📊 Excel Sales & Customer Insights Dashboard

## 📌 Project Overview
This project demonstrates end-to-end data processing, cleaning, formatting, and dynamic reporting using Microsoft Excel. Transactional retail sales data was analyzed to evaluate total revenues across different product categories and identify top sales drivers.

## 🛠️ Excel Tools & Techniques Used
* **Data Cleaning & Formatting:**
  * Cleaned messy customer names and applied `=PROPER()` formatting.
  * Formatted date columns to standardized `YYYY-MM-DD` short date format.
  * Formatted sales figures to Currency (`₦` / `$`) with proper two-decimal precision.
* **Data Analysis with Pivot Tables:**
  * Summarized total revenue generated across product categories (**Furniture**, **Office Supplies**, and **Technology**).
  * Filtered out incomplete or blank entries for accurate reporting.
* **Data Visualization:**
  * Created an interactive **Pivot Chart** (Clustered Column Chart) to visually compare category revenues at a glance.

---

## 📈 Key Findings & Insights
1. **Top Revenue Category:** **Technology** generated the highest total sales volume among all categories.
2. **Balanced Performance:** Both **Furniture** and **Office Supplies** maintained steady sales contributions.
3. **Data Quality:** Standardizing date and revenue formats significantly improved report clarity and usability for decision-making.
